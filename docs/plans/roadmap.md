# 路线图

本文区分已交付能力和未排期方向，不承诺具体版本或日期。用户可观察行为的事实来源是 [系统规格](../specs/agent-system.md)。

详细的产品取舍、需求与验收建议见 [产品演进提案](../PRODUCT-EVOLUTION.md)。提案中的阶段是建议顺序，尚未转为执行计划。

## 已交付基线

- 可发布的 `@paoxia/cpx` npm 包、全局 `cpx` 配置/诊断/生命周期 CLI 与程序化 `AgentSystem` API。
- HTTP 健康检查、测试命令端点、钉钉 Stream 和飞书 WebSocket 文本消息。
- 中英文命令解析和统一结果格式化。
- GitHub 文件读取、创建/修改文件并创建 Pull Request。
- Skill 安装底层能力、动态加载、执行超时和能力注入。
- MCP stdio、WebSocket、HTTP 传输和 JSON-RPC 调用。
- 分支保护、操作黑名单、危险操作确认和 SQLite 审计。
- Web 开发控制台、本机 Codex 任务、账号模型目录、多套配置与有序回退、GitHub PAT 创建引导与凭据接入、隔离 Git 工作区、状态日志和可选 PR 发布。
- Dockerfile、Compose、开发机镜像构建脚本，以及不依赖 NAS 终端的极空间部署、更新与代理配置说明。
- 单元测试与跨组件命令流测试。

## 下一步候选

以下项目来自现有产品方向，但尚未排期：

1. 补齐 CLI 的 Skill 安装、卸载及 MCP 管理命令，使公开接口与底层能力一致。
2. 在现有本机 Agent 任务之上增加持久化队列、并发限制、重启恢复和远程 Agent 注册。
3. 在已有钉钉与飞书长连接上丰富任务状态、卡片和经过授权的跨入口接续。
4. 在已有 Docker 部署上完善图形化引导、诊断、一致性备份和升级恢复。
5. 为公网部署补充认证、速率限制、Skill 隔离和更完整的密钥管理。
6. 将 GitHub 修改从固定 Markdown 追加扩展为可审查的通用补丁流程。
7. 统一 Web 与聊天任务的授权和审计，提供改动审查、验证证据与独立发布流程。

候选项只有在确定目标、验收条件和执行负责人后，才应转成独立执行计划。
