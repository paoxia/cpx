# 路线图

本文区分已交付能力和未排期方向，不承诺具体版本或日期。用户可观察行为的事实来源是 [系统规格](../specs/agent-system.md)。

详细的产品取舍、需求与验收建议见 [产品演进提案](../PRODUCT-EVOLUTION.md)。提案中的阶段是建议顺序，尚未转为执行计划。

## 已交付基线

- 可发布的 `@paoxia/cpx` npm 包、全局 `cpx` 配置/诊断/生命周期 CLI 与程序化 `AgentSystem` API。
- HTTP 健康检查、测试命令端点、钉钉 Stream 和飞书 WebSocket 文本消息。
- 中英文命令解析和统一结果格式化。
- GitHub 文件读取、创建/修改文件并创建 Pull Request。
- Skill 安装底层能力、动态加载、执行超时和能力注入。
- MCP stdio、WebSocket、HTTP 传输和 JSON-RPC 调用。
- 分支保护、操作黑名单、危险操作确认和 SQLite 审计。
- Web 开发控制台、本机 Codex 任务、账号模型目录、多套配置与有序回退、GitHub PAT 创建引导与凭据接入、隔离 Git 工作区、状态日志和可选 PR 发布。
- Dockerfile、Compose、开发机镜像构建脚本，以及不依赖 NAS 终端的极空间部署、更新与代理配置说明。
- 单元测试与跨组件命令流测试。

## 本轮工作站交付

- 管理员认领、scrypt 密码、会话/CSRF、可撤销令牌、项目角色和显式平台绑定。
- SQLite 任务/轮次持久化、串行队列与容量、幂等、中断恢复和通知 outbox。
- Git tree 版本化成果、真实验证证据、独立 PR 发布/对账、补丁导出和保护性归档清理。
- 项目历史规则、跨入口任务链接、运行诊断、一致性数据库备份与旧发布策略迁移。
- 固定间隔模板维护、Skill 子进程与管理 CLI、项目扩展范围工具。
- 默认关闭的远程执行器配对、出站领取、心跳租约、过期结果拒绝和补丁导入；可选的顺序独立只读审查会话。

操作见 [工作站指南](../WORKBENCH.md)，验证结果及具体限制见 [实施记录](product-evolution-implementation.md)。

## 后续验证与未排期方向

- 在目标极空间硬件、实际模型账号和消息平台上执行完整升级/恢复与端到端联调。
- 收集真实任务交付率与资源数据，再决定多 Agent 协作是否值得增加运行复杂度。
- 在当前受管理子进程之上探索真正的容器/操作系统隔离、独立用户凭据与网络策略。
- 增强大仓库 diff 展示、平台卡片、模板编辑和诊断的交互体验。
- 企业身份联邦、多控制端调度、Kubernetes 与不可信多租户隔离尚未排期。

候选项只有在确定目标、验收条件和执行负责人后，才应转成独立执行计划。
