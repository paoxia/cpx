# 路线图

本文区分已交付能力和未排期方向，不承诺具体版本或日期。用户可观察行为的事实来源是 [系统规格](../specs/agent-system.md)。

## 已交付基线

- TypeScript CLI 与程序化 `AgentSystem` API。
- HTTP 健康检查、测试命令端点、钉钉和飞书文本 Webhook。
- 中英文命令解析和统一结果格式化。
- GitHub 文件读取、创建/修改文件并创建 Pull Request。
- Skill 安装底层能力、动态加载、执行超时和能力注入。
- MCP stdio、WebSocket、HTTP 传输和 JSON-RPC 调用。
- 分支保护、操作黑名单、危险操作确认和 SQLite 审计。
- Web 开发控制台、本机 Codex/Claude Code 任务、有序模型回退、隔离 Git 工作区、状态日志和可选 PR 发布。
- 单元测试与跨组件命令流测试。

## 下一步候选

以下项目来自现有产品方向，但尚未排期：

1. 补齐 CLI 的 Skill 安装、卸载及 MCP 管理命令，使公开接口与底层能力一致。
2. 在现有本机 Agent 任务之上增加持久化队列、并发限制、重启恢复和远程 Agent 注册。
3. 增加钉钉长连接、飞书卡片等更丰富的平台交互。
4. 提供 Docker 镜像、持久化卷、健康检查和部署示例。
5. 为公网部署补充认证、速率限制、Skill 隔离和更完整的密钥管理。
6. 将 GitHub 修改从固定 Markdown 追加扩展为可审查的通用补丁流程。

候选项只有在确定目标、验收条件和执行负责人后，才应转成独立执行计划。
