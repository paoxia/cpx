## 文档原则

- 只记录项目事实、已作出的决策和正在执行的计划。
- 避免复制代码可以直接表达的信息；必要时链接到事实来源。
- 不保留空模板、占位符或没有负责人和目标的计划。
- 每项信息只设一个事实来源，其他文档使用链接引用。
