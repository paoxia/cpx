# 设计系统参考文档 (LLMs)

本文档为 AI 模型提供设计系统参考信息。

## 设计系统概述

### 设计原则
1. 简洁性 - 移除不必要的元素
2. 一致性 - 统一的视觉语言
3. 可访问性 - 所有用户可用
4. 性能优先 - 快速响应

### 设计风格
- 参考: Apple Human Interface Guidelines
- 风格: 现代简约，清晰优雅
- 色彩: 克制使用，突出重点

## 常用组件

### 按钮

#### 类型
- Primary: 主要操作
- Secondary: 次要操作
- Text: 文本按钮
- Icon: 图标按钮

#### 尺寸
- Small: 32px height
- Medium: 40px height
- Large: 48px height

#### 状态
- Normal: 默认状态
- Hover: 悬停状态
- Pressed: 按下状态
- Disabled: 禁用状态

### 输入框

#### 样式
- 高度: 40px
- 边框: 1px solid #E5E5EA
- 圆角: 8px
- 内边距: 12px

#### 状态
- Normal: 默认状态
- Focus: 聚焦状态，蓝色边框
- Error: 错误状态，红色边框
- Disabled: 禁用状态，灰色背景

### 卡片

#### 样式
- 背景: 白色
- 圆角: 12px
- 阴影: Small 或 Medium
- 内边距: 16px

## 动画

### 时长
```
Fast:      150ms
Normal:    300ms
Slow:      500ms
```

### 缓动函数
```
Ease:      cubic-bezier(0.25, 0.1, 0.25, 1)
Ease-in:   cubic-bezier(0.42, 0, 1, 1)
Ease-out:  cubic-bezier(0, 0, 0.58, 1)
Ease-in-out: cubic-bezier(0.42, 0, 0.58, 1)
```

## 图标

### 图标库
- 推荐: SF Symbols (Apple)
- 备选: Heroicons, Phosphor Icons

### 尺寸
```
Small:     16px
Medium:    24px
Large:     32px
```

## 响应式断点

```
Mobile:    < 640px
Tablet:    640px - 1024px
Desktop:   > 1024px
```

## 无障碍

### 对比度
- 文本: 至少 4.5:1
- 大文本: 至少 3:1

### 交互
- 点击区域: 最小 44x44px
- 焦点指示: 清晰可见

## 最佳实践

1. 保持视觉一致性
2. 使用设计令牌而非硬编码值
3. 考虑深色模式支持
4. 测试无障碍性
5. 保持动画流畅
