本文档为 AI 模型提供 Nixpacks 构建工具参考信息。

## 什么是 Nixpacks？

Nixpacks 是一个开源的应用构建工具，可以自动检测项目类型并创建可部署的容器镜像。

## 核心概念

### 构建流程
1. **检测**: 自动识别项目类型和依赖
2. **安装**: 安装必要的运行时和依赖
3. **构建**: 执行构建命令
4. **打包**: 创建容器镜像

### 支持的语言

#### JavaScript/TypeScript
- Node.js (自动检测 package.json)
- 支持 npm, yarn, pnpm
- 构建命令: `npm run build`
- 启动命令: `npm start`

#### Python
- 自动检测 requirements.txt, Pipfile, pyproject.toml
- 支持 pip, poetry
- 启动命令: 自动检测

#### Go
- 自动检测 go.mod
- 构建命令: `go build`
- 启动命令: 运行编译后的二进制文件

#### Rust
- 自动检测 Cargo.toml
- 构建命令: `cargo build --release`
- 启动命令: 运行编译后的二进制文件

#### 其他语言
- Ruby (Gemfile)
- Java (pom.xml, build.gradle)
- PHP (composer.json)
- .NET (*.csproj)

## 配置文件

### nixpacks.toml

```toml
[phases.setup]
nixPkgs = ['...', '...']

[phases.install]
cmds = ['...', '...']

[phases.build]
cmds = ['...', '...']

[start]
cmd = '...'
```

### 环境变量

#### 构建时变量
```
NIXPACKS_NODE_VERSION=18
NIXPACKS_PYTHON_VERSION=3.11
NIXPACKS_BUILD_CMD=npm run build
NIXPACKS_START_CMD=npm start
```

#### 运行时变量
```
NODE_ENV=production
PORT=3000
```

## 常用命令

### 本地构建
```bash
# 构建镜像
nixpacks build .

# 构建并指定名称
nixpacks build . --name myapp

# 指定输出目录
nixpacks build . --output ./output
```

### 本地运行
```bash
# 直接运行
nixpacks run .

# 指定端口
nixpacks run . --port 8080
```

### 生成 Dockerfile
```bash
# 输出 Dockerfile
nixpacks plan .
```

## 项目结构

### Node.js 项目
```
project/
├── package.json
├── package-lock.json
├── src/
└── nixpacks.toml (可选)
```

### Python 项目
```
project/
├── requirements.txt
├── main.py
└── nixpacks.toml (可选)
```

## 最佳实践

### 1. 明确指定版本
```toml
[phases.setup]
nixPkgs = ['nodejs-18_x', 'python311']
```

### 2. 缓存优化
```toml
[phases.install]
cache = true
```

### 3. 多阶段构建
利用缓存减少构建时间

### 4. 安全性
- 不在镜像中存储敏感信息
- 使用环境变量配置

### 5. 镜像大小优化
- 清理不必要的文件
- 使用 .dockerignore

## 常见问题

### Q: 如何自定义构建命令？
A: 创建 nixpacks.toml 文件或设置 NIXPACKS_BUILD_CMD 环境变量

### Q: 如何处理私有依赖？
A: 使用构建时的环境变量或挂载凭证文件

### Q: 如何调试构建问题？
A: 使用 `nixpacks plan .` 查看构建计划
