# 新用户引导

## 背景

新用户首次使用产品时，需要清晰的引导流程，帮助用户快速了解产品功能和使用方法。

## 用户故事

**作为** 新用户
**我想要** 清晰的引导流程
**以便于** 快速上手使用产品

## 功能描述

### 引导流程

```
启动应用 → 欢迎页面 → 功能介绍 → 快速上手 → 完成
```

### 页面设计

#### 1. 欢迎页面
- **标题**: 欢迎使用 [产品名称]
- **内容**: 简短的产品介绍
- **操作**: "开始使用" 按钮

#### 2. 功能介绍
- **方式**: 轮播卡片或交互式引导
- **内容**:
  - 核心功能 1: [待补充]
  - 核心功能 2: [待补充]
  - 核心功能 3: [待补充]
- **操作**: "下一步" / "跳过" 按钮

#### 3. 快速上手
- **内容**: 引导用户完成第一个操作
- **示例**: [待补充具体操作]
- **反馈**: 操作成功提示

#### 4. 完成页面
- **内容**: 引导完成祝贺
- **操作**: "开始探索" 按钮

### 交互设计

#### 触发条件
- 首次安装后启动
- 新版本重大更新后首次启动

#### 跳过机制
- 每个步骤都可跳过
- 提供"不再显示"选项

#### 进度指示
- 显示当前步骤/总步骤
- 允许前后导航

### 数据记录

记录用户引导行为：
- 是否完成引导
- 在哪个步骤跳过
- 完成时间

## 验收标准

- [ ] 首次启动自动触发引导
- [ ] 每个步骤可跳过
- [ ] 提供进度指示
- [ ] 可在设置中重新触发
- [ ] 引导完成后显示祝贺页面
- [ ] 适配不同屏幕尺寸

## 技术要求

### 存储
- 使用 localStorage 或 chrome.storage 记录引导状态
- 存储键: `onboarding_completed`
- 存储值: `true/false`

### 多语言
- 支持多语言切换
- 文案可配置

### 性能
- 引导资源预加载
- 动画流畅不卡顿
